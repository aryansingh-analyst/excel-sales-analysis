#  Sales Data Analysis Using Microsoft Excel

##  Project Overview

This project is an end-to-end **Sales Data Analysis project using Microsoft Excel**.

The main objective of this project is to analyze a sales dataset, perform data cleaning and calculations, answer **20 business-related questions**, identify important patterns, and generate meaningful business insights.

The project demonstrates how Excel can be used as a practical **Data Analytics tool** to convert raw data into useful information for business decision-making.

---

##  Project Objectives

The main objectives of this project are:

- Analyze sales performance
- Calculate revenue, cost, and profit
- Clean and organize raw data
- Use Excel formulas for calculations
- Use Pivot Tables for data analysis
- Analyze product and category performance
- Analyze regional performance
- Identify top and low-performing products
- Analyze sales and profit trends
- Answer 20 business questions
- Generate actionable business insights
- Present the analysis in a clear and understandable format
